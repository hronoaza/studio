# Аудит наданих фрагментів і виправлення

Об’єкт: останні фрагменти AudioEngine і offline-audio-test.html у розмові, зіставлені зі специфікацією 1.1. Висновок: початкові фрагменти не повністю відповідали редакції 1.1. Таблиця описує виправлення в цьому пакеті, а не результат виконання початкового браузерного коду.

| Проблема | Наслідок | Виправлення |
|---|---|---|
| knee не встановлено; release = 0.25 | Параметри відрізняються від 6 dB і 0.100 с | Обидва значення задано явно |
| Частоти записано округленими константами | Коментар з формулою не забезпечує її точного виконання | 136.1 / Math.sqrt(2) і 136.1 / Math.sqrt(3) |
| setTargetAtTime використано замість лінійних рамп | Експонента не завершується в заданий час і не досягає нуля | Лінійні рампи 0.8 / 0.5 / 0.3 с; старт із 0 |
| setTimeout після stop | Старий таймер може скинути новий граф; настінний час не є аудіочасом | Зупинка джерел за ctx.currentTime; інвалідація завершень через epoch |
| hardReset під час await resume | Старий start може створити граф після скидання | Перевірка токена після await |
| finally одразу скидає isBusy | Блокування не охоплює фактичну рампу | Стани starting/changing/stopping до завершення аудіопереходу |
| Невідомий modeKey з fallback | currentMode може суперечити фактичній частоті | Явний RangeError до створення контексту |
| Помилки лише в console.error | Викликаючий UI не дізнається про невдачу | Відхилений Promise і видиме повідомлення UI |
| Імпорт рушія в тесті не використано | Тест перевіряє інший, дубльований граф | Спільна createGraph() для live та offline |
| PASS виводився безумовно | Хибнопозитивний результат навіть при порушенні меж | Реальні assert, облік помилок, код виходу runner |
| 0.495 перевірялося після компресора | Змішано модель AM до обробки та фактичний вихід | Окремі канали pre/post і окремі критерії |
| DC усереднювався за 3 секунди | 408.3 періоду та стартовий перехід спотворюють оцінку | Стале вікно з 1361 повним періодом і фазові тести |
| SVG позначено як 512×512 | Для векторної масштабованої іконки коректніше sizes: any | SVG any та окремі PNG |

Оригінальний UI-код у нових повідомленнях повністю не надано, тому твердження про його чистоту не можна було незалежно підтвердити. У наданому пакеті script.js не створює аудіовузлів; створення тракту зосереджене в audio-engine.js.

Інтеграційна зміна API: вузли доступні через engine.graph, а analyser — також через getter engine.analyser. UI використовує тільки методи керування, стани та analyser. Повторні конфліктні команди повертають false; помилки не приховуються.
