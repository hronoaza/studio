## Відтворений дефект тесту
У tests/mesh_tests.cpp вузли 0 та 2 мають координати (0,0,0) і (2,2,2), відстань sqrt(12) ≈ 3.464. Виклик autoConnectNearbyNodes(3.0) не повинен їх з’єднати, але наступний assert очікує два мости вузла 0. Саме цей assert зупиняє Debug і TSan до виклику simulationStepAsync().

## Обмеження Release та sanitizers
Журнал компіляції Release містить -O3 -DNDEBUG. Усі чотири assert у тесті вимкнені, тому успішне завершення не перевіряє закладені в них умови. Повідомлення All SOAM RC Unit Tests Passed successfully! саме по собі не доказ проходження цих перевірок.
Debug містить -fsanitize=address,undefined; окремий TSan містить -fsanitize=thread без ASan. Обидва запуски перервані assert до багатопотокової симуляції. Висновків про відсутність помилок пам’яті чи гонок не зроблено.
